# 网页设置向导

打开「配置 → 设置向导」（`#/config/setup`）。它读取当前生效的配置，已有设置显示「已配置」，无需重新输入 Key。各步骤分别保存，可随时返回；向量、思考判断、代码沙盒和 AGY 都可以跳过，跳过不会修改已有配置。

1. **聊天模型**：选择现有默认模型，或添加提供商和模型。可手动测试连接，会发送一次简短模型请求。「模型分工与备用」可配置后台任务模型、识图模型以及有序备用列表，并检查所选模型的密钥。
2. **联网与阅读（可选）**：选择模型自带搜索或外部搜索，填写所需 Key / SearXNG 地址，独立选择网页读取方式和搜索次数。自带搜索会检查默认模型接口是否支持；Brave/Tavily 缺少有效 Key 或 SearXNG 缺少地址时不会向模型提供搜索工具。搜索和 Jina Reader Key 支持 `env:变量名`。
3. **向量检索**：填写接口类型、地址、向量模型、维度和 Key，保存后开启记忆与向量检索。Key 留空保留已有值。
4. **思考判断 / Jev**：选择 System One（Jev / 自建 Kev）、聊天小模型或关键词规则。保存后开启默认聊天模型的 `auto` 思考强度。Jev Key 支持 `env:变量名`。
5. **用量预算（可选）**：按模型设置每人、每群及全局的滚动 5 小时 / 7 天额度（美元），0 表示不限。表单读取显式额度及简写继承值，保留管理员豁免规则和已用额度；保存所选模型不会更改其他模型的设置。
6. **代码沙盒（可选）**：保存 WSL 发行版与使用权限，按向导中的命令在机器人主机安装，再重新检查环境，通过后启用。
7. **电脑操作（可选）**：选择持久桌面环境、视觉/工具模型和权限，通过环境及模型检查后启用。已有 WSL 环境可复用。
8. **图片反搜（可选）**：配置 Google Lens 的发行版和权限，按说明准备桌面与浏览器环境。可以独立启用，无需开启电脑工具或 AGY 代理。
9. **AGY（可选）**：先配置 WSL 与桌面，再运行 AGY 安装命令并在本机登录 Antigravity。检查 CLI、模型目录访问、沙盒桥接、隔离与桌面服务后才能启用。实际任务授权和模型访问仍以 CLI 返回为准；`node cli/agy-verify.mjs` 可进行完整验证，会使用 AGY 额度。

「已配置」表示配置项完整；模型、向量与 Jev 的凭据有效性仍由对应服务验证。环境检查不会执行安装脚本或发送模型生成请求。检查结果缓存 60 秒，相同检查并发合并；「重新检查环境」可强制刷新。

环境未就绪时，即使配置中的 enable 开关已打开，`run_code`、`agy`、`computer_task`、`google_lens` 也不会提供给聊天模型。电脑工具还要求有效的视觉/工具模型。工具执行前再次检查可用性，防止继续使用已失效的工具清单。「工具与技能」页面会标记未就绪工具。

技能可以在 frontmatter 中声明 `requires_tools: [run_code]` 等依赖。缺少任意工具时，该技能既不会进入系统提示，也不能通过 `load_skill` 加载。自带 computer-use、google-lens 技能声明了相应依赖；它们也受当前会话权限、工具禁用清单和环境状态约束。

认证接口 `GET /api/setup` 返回状态与检查项目，不返回 Key 或 CLI 输出；`?refresh=1` 强制重新检查。`PUT /api/setup` 对向导的一批修改统一校验并一次写入，错误时整批不保存，未修改的 Key 和 YAML 注释保留。后端更新需要重启机器人；网页表单配置本身热重载。
