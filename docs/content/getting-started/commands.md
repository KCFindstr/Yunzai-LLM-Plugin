# 常用指令大全

Yunzai-LLM-Plugin **默认只在被 @ 机器人或引用机器人消息时触发对话，不会抢占群内已有插件的指令。** 可按群开启[主动发言](/models/thinking#主动发言)。

---

## 基础对话与交互

| 触发方式 | 说明 | 适用范围 |
| :--- | :--- | :--- |
| `@机器人 <想说的话>` | 向机器人发起对话。附带图片、文件也会自动被视觉或文件解析器处理。 | 所有群成员 |
| 引用机器人的消息回复 | 继续上一轮会话或针对机器人的回答追问。 | 所有群成员 |
| 私聊发送任意文本 | 私聊直接开启大模型会话（若文本以 `#llm` 开头则进入管理指令）。 | 由 `trigger.private` 决定，默认仅主人 |

---

## 用户日常查询指令

所有普通用户均可在群聊或私聊中使用以下指令查看自身用量与状态：

| 指令 | 说明 |
| :--- | :--- |
| `#llm帮助` | 查看帮助菜单。管理员发送时会额外列出全部管理指令（合并转发）。 |
| `#llm状态` | 查看插件与本群是否启用、当前模型与思考强度、本会话的记忆条数；管理员还能看到会话、指令目录、表情、工具与长期记忆等统计。 |
| `#llm额度` | 查看自己近 5 小时与近 7 天的用量与剩余额度。 |
| `#llm清除记忆` | 清空当前对话上下文与短期会话历史，开始全新的一段对话。 |
| `#llm记忆` / `#llm忘记我` | 查看 / 清空机器人记住的关于自己的长期记忆。 |

## 管理员与运维配置指令

:::info 权限说明
只有 Yunzai 主人或在 `admins` 配置列表中指定的管理员 QQ 号有权执行以下配置指令。
:::

### 1. 模型与提供商管理
```text
#llm模型列表                                      # 查看系统注册的所有模型及能力标识
#llm切换模型 <模型ID>                              # 切换全局默认聊天模型 (如 #llm切换模型 deepseek-pro)
#llm测试模型 [模型ID]                              # 向模型（默认为默认模型）发送一条测试消息，返回耗时与回复
#llm设置密钥 <提供商ID> <API-Key>                   # 绑定或更新提供商的 API 密钥
```

### 2. 额度控制管理
```text
#llm额度设置 <模型ID> <范围> 5h=<美元> week=<美元>
```
- **范围** 可选：`user` (每人)、`group` (每群)、`global` (全局)
- 示例：
  - `#llm额度设置 deepseek-pro user 5h=1 week=2`：限制每位用户使用 deepseek-pro 每 5 小时最多 $1，每 7 天最多 $2。
  - `#llm额度设置 deepseek global 5h=10 week=50`：限制全局使用 deepseek 每 5 小时不超过 $10。

### 3. 表情包管理
```text
#llm添加表情 [附带图片或引用图片消息]
```
- 管理员发送带有图片的消息并附带该命令（或引用一条图片消息），视觉模型将自动识别并生成名称、描述与标签，存入表情包图库。

### 4. 任意配置热修改
```text
#llm设置 <配置路径> <值>
```
- 示例：
  - `#llm设置 reply.markdown true`：开启 Markdown 排版支持。
  - `#llm设置 chat.maxToolRounds 8`：设置单次回复最大工具轮次为 8 轮。

### 5. 指令与技能探索
```text
#llm指令列表                                      # 查看自然语言可调用的机器人插件指令
#llm测试指令 #深渊                                # 检查这条指令会由哪个插件处理
```

完整的管理指令（模型、提供商、价格、人设、表情、工具、技能等）请发送 `#llm帮助` 查看。
