# 自然语言转机器人指令

在传统的 QQ 机器人使用中，用户必须死记硬背枯燥的固定指令格式（如 `#原神深渊`、`#抽卡分析`、`#刷新列表` 等）。一旦记错前缀或漏打空格，就会毫无反应。

Yunzai-LLM-Plugin 能把口语请求转换成已启用插件的指令，并以提问者身份执行。

---

## 运作原理与架构设计

### 1. 运行时动态扫描与发现
- 插件会扫描 Yunzai-Bot 当前已加载的其他插件（如喵喵插件、抽卡插件、工具插件等），提取规则表和帮助菜单中声明的触发命令与功能描述。
- 只有验证过能被插件处理的指令才会推荐给模型，群里禁用的插件不会推荐。管理员可用 `#llm扫描指令` 重新扫描、`#llm指令列表` 查看。

### 2. 意图理解与精确匹配
- 当用户以自然口语提问（例如：“帮我查一下我上期的原神深渊记录呗”、“给我抽十发刻晴池子”）：
- 系统提示中列出常用指令（`tools.botCommand.inPrompt`），其余由大模型通过 `search_bot_commands` 搜索，找到最契合的指令（例如 `#深渊`）后用 `run_bot_command` 执行。

### 3. 以用户原身份重新分发
- **核心安全保障**：大模型决定执行某个机器人指令时，指令并**不是**以机器人自己的超级权限执行，而是**以提问者原本的用户身份和群内角色**重新分发给 Yunzai 核心分发总线！
- 原插件的一切权限控制（如：仅管理员可用、仅限私聊、黑名单群）全部原样生效。
- 重启、更新、安装插件等危险指令默认在 `tools.botCommand.blacklist` 中禁止；主人权限指令需开启 `tools.botCommand.allowMasterCommands` 才能通过对话执行。
