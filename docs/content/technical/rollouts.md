# 执行记录 (Rollouts) 机制

在复杂的群聊或多轮工具调用中，仅仅查看最终文字回复很难复盘大模型的真实思考链、工具执行耗时与中间报错。

Yunzai-LLM-Plugin 内置了一套工业级的**执行记录（Rollouts）系统**。

---

## 核心设计特性

### 1. 完整时间线与逐轮快照
- 记录思考强度的选择过程（固定配置或判断模型的结果）、模型每一轮的响应与接口返回的思考摘要、工具调用参数与返回结果、最终回复，以及模型、耗时、token 和费用。
- 本轮初始请求的系统提示、工具定义和聊天上下文也会保存，可点 **原文** 查看完整请求。
- 在 Web 面板 **「对话与记忆 → 执行记录」** 以时间线呈现，每 3 秒自动更新。

### 2. 敏感信息自动脱敏
- 在序列化存储到磁盘之前，系统会自动过滤并擦除 API Key、密码、认证 Token 等私密凭据。
- 输入上下文中的图片只记录数量；工具返回给模型的图片单独保存（每张最多 10 MiB，每次执行最多 64 张），可在工具步骤中查看。

### 3. 分散持久化与滑动淘汰
- 每一条执行记录独立保存为 `Yunzai/data/Yunzai-LLM-Plugin/rollouts/<执行ID>.json`，列表只读取轻量索引 `index.json`。
- 记录保留 30 天，启动时、访问时和每小时自动清理过期记录与图片。
