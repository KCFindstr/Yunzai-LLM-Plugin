# 聊天执行记录（Rollouts）

网页管理面板的 **对话与记忆 → 执行记录（Rollouts）**（`#/rollouts`）使用与 AGY 相同的列表和时间线布局。每次主聊天模型执行单独展示，包括排队/执行/完成/失败状态、用户输入、各轮可见模型响应、工具参数与结果、最终生成的回复，以及模型、耗时、token 和费用。工具并行执行时，各自返回后立即记录结果。页面每三秒更新，支持筛选；“对话”的最近记录弹窗也可直接进入对应执行。

AGY 和电脑任务完成后，主聊天模型整理结果的轮次也会单独记录，并链接到来源任务。最终回复表示模型生成完成，不代表消息已成功送达聊天。

认证接口为 `GET /api/rollouts`（支持 `?conv=<会话键>`）和 `GET /api/rollouts/:id/history`。记录保存到 `data/rollouts.json`，保留最近 300 次执行，总体最多约 8 MiB；正在运行的执行不会因数量限制被移除。每次执行最多保留 500 条 / 256 KiB 事件，超出时显示截断提示。重启后未结束的执行标记为已中断。

记录复用 AGY 的敏感信息过滤，写入和读取时均过滤密钥、私有路径等内容；只记录可见文本和工具数据，不保存原始图片、系统提示或供应商内部推理。详细记录从更新后新开始的执行生效，旧对话摘要仍在“对话”中查看。构建后重启机器人以加载后端记录逻辑。
